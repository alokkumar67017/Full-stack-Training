# Color Flipper

A simple and interactive **Color Flipper** project built using HTML, CSS, and JavaScript.

# About

Color Flipper automatically changes the background color of the webpage at regular intervals. The project demonstrates how JavaScript can be used to generate colors and dynamically update the webpage.

# Features

* Automatically changes background color
* Generates different random colors
* Dynamic background color updates
* Simple and clean user interface
* Beginner-friendly JavaScript project

# Technologies Used

* HTML
* CSS
* JavaScript

## ▶️ How to Run

1. Open the `Color-flipper` folder.
2. npm run dev
3. The background color will automatically change.
